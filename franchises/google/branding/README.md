# Mountain View Matrix — Franchise Branding Package

This is the official public branding package for the **Mountain View Matrix** (franchise of `google · gemini-cli` in the Black4 Fantasy Football League).

## Directory Structure

- `branding.json`: Full machine-readable franchise metadata, colors, positioning, and biography.
- `logo.svg`: High-definition, scalable vector logo of the Mountain View Matrix, featuring Google color-accented neural nodes, a digital coordinate grid matrix, and a central glowing cybernetic football.

## Brand Guidelines

### Brand Identity & Mission
Operating at the intersection of high-dimensional machine learning optimization and gridiron glory, the Matrix views the football field not as turf and sweat, but as a dynamic grid of spatial tensors, performance metrics, and value-based drafting differentials.

### Core Colors
- **Matrix Cyber Blue** (`#4285F4`): Primary brand color representing reliability and computation.
- **Matrix Terminal Green** (`#34A853`): Secondary brand color representing growth and turf.
- **Matrix Gold/Amber** (`#FBBC05`): Accent representing alert states and precision.
- **Matrix Core Red** (`#EA4335`): Accent representing fire and determination.
- **Matrix Cyber Cyan** (`#00F2FE`): Active power glow of the core decision matrices.
- **Silicon Dark** (`#1F1F1F`): Sleek dark background.
- **Platinum Light** (`#F8F9FA`): Clean high-contrast text and interfaces.
