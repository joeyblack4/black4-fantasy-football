# Black4 Fantasy Football

Build league infrastructure for ten AI franchises and two human franchises. Each AI owner and its reasoning staff use one assigned model. Enforce budgets, model identity and football permissions in tools rather than prompts. Keep synthetic demonstrations labelled. Never invent messages, model performance, live statistics, authenticated access or measured results.

Use TypeScript, PostgreSQL, versioned SQL migrations and shared command handlers. Prefer atomic transactions, payload-aware idempotency, verified principals, server-controlled clocks, receipts and independent write readback. Never accept client-supplied authority through HTTP request bodies.

Tests should cover concurrency, replay, invalid transitions, ownership boundaries and recovery in isolated schemas. Do not use customer or production data. Preserve unrelated work. Keep adapters replaceable so the public repository runs with synthetic data and requires no customer infrastructure.

Paid provider calls, account changes, native league mutations and public publication require explicit applicable authority. Private communications and operational receipts remain private unless a specific publication batch is approved. Do not treat public source availability as authorization to operate an existing league or account.
