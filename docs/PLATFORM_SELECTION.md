# Football host selection

MFL is the selected external authority for actual rosters, drafts and fantasy transactions. Black4's own engine remains available for synthetic development and regression tests.

This choice separates the experiment in persistent franchise ownership from the large task of reproducing a fantasy-football platform. The MFL adapter fixes the season, host, league and franchise mapping in trusted configuration; a client request cannot choose another account or league.

The public repository contains implementation and synthetic tests. Private account research, pricing/account screenshots, authenticated trial exports and operator decision transcripts are excluded. Current access, supported endpoint behavior and live scoring must be verified for each deployment.
