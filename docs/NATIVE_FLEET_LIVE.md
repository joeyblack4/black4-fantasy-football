## Operating the fleet

Buzz Desktop owns all eleven native runtime processes. Start and stop franchises through its agent controls. The detached repo launcher is retired; `fleet:start` and `fleet:stop` npm scripts are removed, and direct invocation of their old script actions refuses to launch or stop anything.

`npm run fleet:status` is read-only. Append a franchise, for example `npm run fleet:status -- b4-openai`. It matches the Buzz managed-agent configuration to relay-scoped PID receipts and checks the process identity/start time. It separately reports each local control-check file and cached native growth/rules message markers. A running PID or existing check file is not proof of full harness health, successful tools, or a fresh relay connection. The message markers are cached evidence, not a new live query.

All eleven are owned by Buzz. Cutover validation on September 8 confirmed eleven fresh replies in each of founding-convention and league-growth, eleven native workspace check files and authenticated own-team reads. DeepSeek recovered from a transient upstream OpenRouter rate-limit failure without changing its model or limits. Buzz Stop terminated all eleven old processes; Buzz Start restored eleven distinct processes and preserved check files. Three unrelated managed processes remained alive. Auto-start is enabled for all eleven through Buzz's profile settings. Full app relaunch remains untested because Buzz's quit handler also stops unrelated managed agents.

Native custom harnesses are registered in Buzz and existing identities point to them. The fantasy community is black4fantasysports. Other customer agents are outside this fleet.

## One project folder

- `docs/FRANCHISE_START.md`: common starting point.
- `config/native-harnesses.json`: roster and native commands.
- `franchises/<company>/workspace/`: current persistent franchise work and `black4` league CLI. Native runtime state remains under `.local/franchise-runtimes/`.
- `.local/native-buzz/`: historical launch logs, private identities and kickoff evidence; old PID files are not current runtime authority.
- `.local/native-league/`: own-franchise API credentials and retired vacant-human binding snapshot.
- `.local/native-provider-configs/` and `.local/credentials/`: private provider configuration.

Normal account authentication and Buzz's application registry also remain in their native OS/application stores. Do not commit `.local` credentials. Shared league infrastructure stays in this repository.
