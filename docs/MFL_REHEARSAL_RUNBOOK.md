# Native draft rehearsal

Use an explicitly disposable MFL league. Keep the real league separate. Before any destructive reset, obtain applicable authorization, preserve a backup, inspect current supported native forms and independently verify exact league/season identity.

The runtime's rehearsal gate uses the same canonical owner wallets. It temporarily binds a reviewed trial host version, admits only explicitly tagged jobs, restricts football actions and retains costs and unknown holds across attempts. It does not clone budgets or erase prior spending. Restoration requires quiescence and reconciled native operations.

Configure and verify the selected rules, native live draft mode, exact draft order, roster size, eligibility and empty completed-pick history. Timer-disabled drafts require an operator stall plan. For an agent experiment, disable third-party expert/ADP auto-selection; owner queues are preferences unless explicit standing authority exists. Never present operator human-seat fixtures as a human participant's real strategic decisions.

Preserve a fresh model decision per pick when that is the claimed experiment. Budget for all model/read/repair turns and keep the next full reservation available. Inspect per-owner cost after early rounds, preserve unresolved charges and stop at the approved cap. A full16-round draft requires16 AI pick decisions per AI owner; this is not guaranteed by a small demonstration.

Private league identifiers, session references, reset form tokens, live commands and operational receipts are excluded. Review `src/runtime/rehearsal.ts`, `src/runtime/mfl-draft-observer.ts`, `src/mfl/draft-queue.ts` and their synthetic tests for current behavior. Source availability does not authorize a live draft or prove that one has completed.
