# Operator workbench

Visual thesis: an understated football operations desk with clear typography, dark ink, warm paper and one green accent; show recorded facts and pending work without implying simulated activity is real.

Content plan: primary franchise roster/work queue; selected franchise conversation and wake inspector; source freshness and accounting; explicit synthetic/local status banner. This is a functional review surface, not the public launch website.

Interaction thesis: selectable franchise rows reveal one focused inspector; live refresh highlights changed data briefly; mobile stacks the same sections without hiding errors. Respect reduced motion. No ornamental dashboard cards or fabricated rankings.
